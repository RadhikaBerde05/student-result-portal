# Student Result Portal Deployment Using DevOps

## Objective

To automate website deployment using GitHub, Jenkins, Docker, and CI/CD practices.

## Technologies Used

* HTML
* CSS
* JavaScript
* Git
* GitHub
* Docker
* Jenkins

## Features

* Student Result Checking
* Dockerized Application
* Automated CI/CD Pipeline
* GitHub Source Control

## Project Workflow

1. Develop Website
2. Push Code to GitHub
3. Jenkins Fetches Source Code
4. Docker Builds Image
5. Jenkins Deploys Container
6. Website Runs on Localhost

## Conclusion

This project successfully demonstrates DevOps practices by automating the deployment process using GitHub, Jenkins, and Docker.
